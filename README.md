# ECA: Extrapolative Correlation Attention  

This is the official repository for the ICLR 2026 poster paper:

> **Breaking the Correlation Plateau: On the Optimization and Capacity Limits of Attention-Based Regressors**

---

## 📌 Overview

This repository contains the implementation of **Extrapolative Correlation Attention (ECA)**, a novel attention module designed to overcome optimization and capacity limits in attention-based regression models.

Currently, the following resources are available via [Openreview supplementary](https://openreview.net/forum?id=hcKK5F6Hlf), which includes:

- ✅ ECA module implementation
- ✅ Synthetic dataset
- ✅ Spatio-transcriptomic dataset (EGN)

Additional experiments and full training pipelines will be released after the ICLR 2026 conference in this repository.
